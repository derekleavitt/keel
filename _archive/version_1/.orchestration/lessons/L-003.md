# Every export from a 'use server' module is a public HTTP endpoint

An agent's first draft exported currentUserId() from an actions file, which would have
published the signed-in user's id as a callable endpoint. It caught this itself; nothing
in the repo would have.

Documented in .claude/rules/server-actions.md. Promote to a lint rule when Biome supports
the directive-aware check — until then this is level 5 and should be treated as
under-enforced.
