# The document nobody's task owns is the one that goes stale, and it is usually the front door

The README still said **"Status: Phase 0 of 6"** after twenty-four features had shipped. It
listed TypeScript 7, reverted at Phase 0.1 after measuring it slower. It advertised a two
second gate. It described the graph layer, territories and the build loop as "designed but not
yet implemented" — a claim the project had spent ten iterations disproving.

Every other document stayed accurate, because each task updated the ones it touched. Nothing
touched the README, because no feature is *about* the README.

**The staleness risk is not proportional to how often a document is edited — it is inverse to
it.** `docs/api.md` changed with every endpoint. `CLAUDE.md` changed whenever a convention
did. The front door changed never, and it is the only document most readers will ever open.

The pattern generalises past READMEs: an architecture overview, a "getting started", a
top-level status. Anything summarising the whole is owned by no part of it.

## What it says about the prediction it invalidates

This is the strongest evidence in the repository for the documentation-staleness gate that
[[P2-02]] predicted — and it also shows why that prediction's *mechanism* would have missed it.
Signature hashing detects code changing under a document that references it. The README
references nothing; it describes a state of the world. No hash would have moved.

What would have caught it: a check that a document claiming "not yet implemented" still has
something unimplemented, or simply **reading the front door as part of finishing**. The second
is not automatable and was the actual failure — I verified a cold clone installed and passed
the gate, and did not read the first thing a new user sees until afterwards.

Related: `/admin/jobs` carried an accurate comment saying role-gating would arrive with T-18
and sat there for six tasks while every customer could read every tenant's failing job
payloads. Same shape — a true statement about the future that nothing re-checked once the
future arrived.
