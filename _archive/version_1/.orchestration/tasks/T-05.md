# Tags: create, attach, detach

Tags slice across lists. That is the entire point of them.

## Acceptance

- [x] `tag` and `todo_tag` tables; deleting a tag never deletes a todo
- [x] Cascade direction asserted by a test, not a comment
- [x] Tags are global to the user, never scoped to a list
- [x] Inline tag creation while tagging a todo

## Watch for

Many-to-many across two feature packages. Expect the cross-territory ownership
question to sharpen: which package owns the join table?

This section is a hypothesis, not a specification. If the friction lands somewhere else,
that is the more interesting result — record it.
