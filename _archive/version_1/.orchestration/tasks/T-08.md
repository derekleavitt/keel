# Search todos by title and notes

Text search, with user-typed wildcards escaped.

## Acceptance

- [x] `%` and `_` typed by a user are escaped, with a test proving it
- [x] Search is scoped to the user like every other query

escaping obvious or easy to forget is a real signal about Keel.

This section is a hypothesis, not a specification. If the friction lands somewhere else,
