# Full-text search across todos and lists

Every list view eventually outgrows a LIKE query.

Proves the **search** row in `docs/platform-readiness.md`. A capability is not done until
the testbed genuinely uses it, a worked example exists for it, the gate covers it, and the
vendor behind it could be swapped without touching feature code.

## Acceptance

- [x] Ranked results across titles, notes and list names
- [x] Scoped to the organization, with a test proving no leakage
- [x] Indexing keeps up with writes
- [x] Search is behind a boundary so the engine can be replaced

## Watch for

First feature reading across every feature package at once, which sharpens the
ownership question T-07 opened.

A hypothesis, not a specification. If the friction lands elsewhere, that is the more
interesting result — record it.

## Outcome

Nobody searches across features: each exposes a `SearchSource` over its own tables under its
own visibility rule, and a composition package merges and ranks. The ownership question the
task anticipated dissolved rather than needing an answer.

The expensive part was unrelated to search. See
`.orchestration/journal/2026-08-28-T-19.md`, [[L-039]], [[L-040]] and [[L-041]].
