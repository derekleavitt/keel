# T-02 — lists

First feature package built on Keel. 26 unit tests (15 ordering, 11 PGlite with two users)
plus 3 browser tests. Cross-user isolation asserted on every operation.

## Did `examples/notes` work as a reference?

**Yes.** The query layer was copied almost mechanically: branded `UserId` first, database
handle last with a `db()` default, `ownedBy()` composing the scope, `and(...) ?? owner` for
the `noNonNullAssertion` rule. None of it needed to be re-derived, and none of the three
seams three agents invented in run 2 got invented again.

That is the clearest evidence yet for the promotion ladder: an example is worth more than
the rule describing it.

## Friction promoted

**K-003 — nothing owned `revalidatePath`.** Server actions must invalidate the cache;
feature packages must not depend on `next`. `@keel/auth/session` solves this for
`headers()` by exposing `requireUser()`, but nothing owned cache invalidation.

Predicted in run 2 as [[L-008]] and never demanded until now. Three agents then worked
around it three ways: return a hint for the app layer, add `next` as a peer dependency,
ship without revalidation and let the page go stale.

`@keel/runtime` now owns the sanctioned crossings, and records *why* each is allowed —
`revalidatePath` because invalidation is inseparable from the mutation; `headers()`,
`redirect()` and route types deliberately not.

**L-008 promoted from `rule` to `lint`.** `biome.json` now blocks `next/*` imports inside
feature packages with a message naming the replacement. Three agents read the rule and
worked around it anyway; a rule you must read is weaker than one you cannot violate.

## A guard that would have decayed

The schema-assembly test hardcoded `authTables`, so adding `list` broke it. A guard that
must be edited every time a feature lands gets edited to pass rather than fixed — and then
it is no longer a guard. It now discovers `*Tables` exports automatically.

Worth watching for elsewhere: enforcement that does not scale without manual updating
decays into decoration.
