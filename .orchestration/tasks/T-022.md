# Make the agent harness refuse bad arguments and unpriced models before it spends

The guardrails from T-016 exist so that the first real run cannot spend by accident. Four paths
around them were found by reading `main()` and confirmed with `--mock` (third grooming):

- `--concurrency abc` becomes `NaN`; `pooled()` then builds an `Array.from({ length: NaN })` of
  zero workers, **no call is made**, and the run reports `result FAIL` with `missing 4: [1,2,3,4]`,
  exit 1. With a credential, that output reads as "the model lost every number". The dry-run and
  max-spend paths validate concurrency (because `project()` does); the plain run path does not.
- `--agents abc` prints `NaN agents`, makes no call, and reports **`PASS`, exit 0**. `--agents 0`
  does the same. `--agents 2.5` makes 2 calls and passes. A pass with no work is the one result
  the oracle must never give.
- A real transport with a `--model` id that is not in `src/pricing.mjs` runs, and `costOf()` prices
  it with `{ input: 0, output: 0 }`: 3000 tokens in and 3000 out report `cost $0.0000`, the
  record's `costUsd` is 0, and `compare.mjs` then shows a measured cost of nothing. The README's
  exit-code table says 2 for "a model whose price is unknown"; that is true only under `--dry-run`
  and `--max-spend` today.
- The default `--out` is `runs/agents-<topology>-<agents>.txt`. Two concurrent runs with the same
  topology and N share it, and `shared-lock` reads the file back between calls. This is the layout
  T-007 fixed in `run.mjs` ("named with its process id, so there is nothing shared to contend
  over"), surviving in the agent harness.

Also folded in, because they live in the same files: `JSON.stringify(Infinity)` writes
`"concurrency":null` into a record made with `--concurrency Infinity` (confirmed), and the
`src/worker.mjs` header lists `naive | lockfile | append` as the strategies, omitting `hierarchical`.

## Acceptance
- [ ] `--agents` must be an integer >= 1; `--concurrency` must be an integer >= 1 (so `Infinity`
      is rejected and the null-in-record case cannot arise); `--fanout` stays as it is. Each
      failure exits 2 with a message naming the flag and quoting the value, before the credential
      check and before any transport is built. A test spawns the CLI with `--mock clean` for
      `--agents abc|0|2.5|-1` and `--concurrency abc|0|Infinity|2.5` and asserts exit 2, empty
      stdout, and the flag name in stderr.
- [ ] `runAgents()` itself throws on a non-integer or non-positive `agents` or `concurrency`, so
      the in-process API has the same floor; a test asserts both.
- [ ] A non-mock run whose resolved model id is not a key of the pricing table exits 2 before the
      credential check with a message naming `src/pricing.mjs`; a test asserts it with no
      `ANTHROPIC_API_KEY` set and `--model claude-sonnet-4-5`, and that `--mock` runs are
      unaffected (their label is `mock:<mode>` and they cost nothing). `--model <alias>` and
      `--model <id that is in pricing.mjs>` still work.
- [ ] The default `--out` includes the process id: `runs/agents-<topology>-<agents>-<pid>.txt`.
      An explicit `--out` is unchanged. A test asserts two concurrent default-path `--mock` runs
      of the same shape write to different files (parse nothing from stdout; compute the expected
      path from the child's pid, as `test/run-isolation.test.mjs` does).
- [ ] `--dry-run` and the `--max-spend` preflight pass `fanout` into `project()` for the
      hierarchical topology. Update the test in `test/agents-guardrails.test.mjs` that compares
      dry-run output against `project()` for `hierarchical --fanout 3` so that it also passes
      `fanout: 3` to `project()`. This passes both before and after T-020 lands (the key is ignored
      until then, honoured after), which is the point: no merge-order dependency. After both land,
      `node src/agents.mjs --agents 12 --topology hierarchical --fanout 3 --dry-run` must print
      `calls 19`, not `15`; T-023 checks that.
- [ ] `src/worker.mjs` header lists all four strategies.
- [ ] **Unchanged, byte for byte**, because README.md quotes them and `test/readme.test.mjs`
      compares them to live output: the first two lines of `--agents 100 --topology partitioned
      --model haiku --dry-run`; the stderr of `--agents 100 --topology partitioned --max-spend 0.01`;
      every `report()` line; the `--record` format (eleven call keys in order, twelve summary keys
      in order — `src/compare.mjs` reads it and is being edited concurrently by T-020). Diff
      before/after for each.
- [ ] **Unchanged, as source text**: the literal substrings `arg('agents', 10)`,
      `arg('concurrency', 20)` and `arg('fanout', 10)` in `src/agents.mjs`, and the helper name
      `arg(` for every flag read. `test/readme.test.mjs` asserts the first three and extracts flags
      with `(?:arg|num|numberArg)\(`. Read the raw value with `arg(...)` as today and validate it
      afterwards.
- [ ] `npm test` exits 0 with no exceptions, and `npm run check` exits 0. This task adds no flag,
      so the flag-documentation test cannot go red. The default `--out` path is not pinned by any
      test; the README sentence that states it is T-023's.
