# README: concurrency, the measurement instruments, and what the harness cannot measure

Last task in this wave set; it quotes numbers and flags that every other task produces. Four
corrections and one addition.

**The crossover table has an unstated condition.** It is computed at unlimited concurrency.
At the harness's own default (`--concurrency 20`), `partitioned` at N=100 is 7.6s against
`solo`'s 4.0s and does not win at zero work; `node src/cost-model.mjs --agents 100 --crossover
--concurrency 20` gives the threshold where it does. Say this next to the table, quote the
tool's numbers, and pin them.

**The harness measures half the table.** `src/agents.mjs` makes API calls. The `claude-code`
rows — the ones that carry the "what you mean by agent dominates everything" finding — have no
instrument in this repository and cannot be measured by anything here. The README currently
says the harness reports "the three things the cost model only projects" without that caveat.

**The real-run command does not work from a fresh checkout.** `node_modules/` is absent;
`@anthropic-ai/sdk` must be installed first. The command block needs `npm install` and the
`--dry-run` line that T-016 added, which is the one to run first.

**The "Open" section.** "Measure it" stays, but it now has a procedure: `--dry-run`, then a
run with `--record`, then `node src/compare.mjs`. Replace the paragraph that says the model
"is probably wrong somewhere" with the specific place T-017's body argues it is wrong — the API
overhead constant against the harness's actual ~45-token prompt — framed as the first thing a
real record will confirm or refute.

**New flags and files.** `--concurrency` for the cost model, `--record`, `--dry-run`,
`--max-spend` for the harness, `src/compare.mjs` in the Layout block. `test/readme.test.mjs`
is red on exactly these until this task lands.
