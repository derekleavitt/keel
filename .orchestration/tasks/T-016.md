# Dry-run projection and a spend ceiling for the agent harness

When a credential appears, someone will type `node src/agents.mjs --agents 100 --topology
shared-lock` and the harness will make 100 serial calls before anybody sees a dollar figure.
The projected cost of that run exists (`project()` in `src/cost-model.mjs`) and the harness
does not consult it. Nor does it stop: a run that is going wrong (a model that answers every
prompt with a paragraph, a rate limit that errors 80 of 100 calls) spends to the end.

Two guards. `--dry-run` prints the projection for exactly the run that would be made — N,
topology, model, fanout, and the harness's own `--concurrency` passed through to the
concurrency-aware model from T-014 — and exits without a credential, an SDK, or a call. It also
says whether `@anthropic-ai/sdk` is installed, because it is not in this checkout
(`node_modules/` is absent) and the README's real-run command would fail on that before it
failed on credentials. `--max-spend <usd>` stops issuing new calls once the measured cost of
completed calls exceeds the ceiling, lets in-flight calls finish, reports what was spent and
how far the run got, and exits 1.

## Acceptance
- [ ] `node src/agents.mjs --agents 100 --topology shared-lock --dry-run` exits 0 with no `ANTHROPIC_API_KEY`, no `--mock`, and no `node_modules`; it makes no call (a test asserts via a scripted transport that `call` is never invoked when `dryRun: true` is passed to `runAgents`, or that the CLI does not reach the transport — either is acceptable, but one must be asserted)
- [ ] The dry-run output contains a line `projected  calls <n>  tokens <in> in / <out> out  cost $<x.xxxx>  time <s>s  (concurrency <c>)` whose values equal `project({ agents, model, kind: 'api', topology, concurrency })` for the same arguments, cost to 4 decimals; a test spawns the CLI for `partitioned`, `hierarchical --fanout 3`, `solo`, `shared-lock` at N=12 and compares each against `project()`
- [ ] The dry-run output contains either `sdk  installed` or `sdk  not installed (run npm install)`, decided by attempting `import('@anthropic-ai/sdk')` and catching `ERR_MODULE_NOT_FOUND`
- [ ] `--dry-run` with `--model` set to an alias prints the full model id from `src/pricing.mjs`; with an id not in the pricing table it prints `pricing  unknown model id; cost cannot be projected` and exits 2
- [ ] `runAgents({ ..., maxSpend })` stops starting new calls once the cost of completed calls (priced as `report()` prices them) exceeds `maxSpend`; a unit test with `concurrency: 1`, ten agents, a scripted transport returning `{ inputTokens: 100, outputTokens: 5 }` on haiku pricing, and `maxSpend` equal to four calls' cost asserts `usage.calls` is 5 (the call that crossed the line completed, the sixth never started), `outcome.ok === false`, and `outcome.stopped` matches `/spend ceiling/`
- [ ] The CLI accepts `--max-spend <usd>` (positive number, else exit 2), prints `stopped   spend ceiling $<x> reached after <k> calls ($<y> spent)` when it trips, and exits 1
- [ ] With `--max-spend` not set, behaviour and output are byte-identical to before this task for `--mock clean` runs at N=8 on every topology (a test compares against the same run with `--max-spend 1000`, which must also be identical because mock tokens cost 0)
- [ ] `npm test` exits 0 **except** `test/readme.test.mjs`'s flag-documentation test, which fails on `--dry-run`, `--max-spend` (and `--record` from T-015) until T-019 documents them; no other test may fail. `npm run check` exits 0

## Notes
- Depends on T-014 for `project({ concurrency })` and on T-015 because both edit `src/agents.mjs`. Do not start until both are merged.
- `kind` is always `'api'` here. The harness makes API calls and nothing else; it cannot measure the `claude-code` column, and the dry-run must not pretend to. Print `kind api` in the dry-run header so that is visible.
- `--dry-run` must not require credentials or the SDK: check the flag before the credential check in `main()`.
- The spend check is on **completed** calls, so with `concurrency` c the overshoot is at most c calls. Say so in the `stopped` line (`up to <c> further calls may have been in flight`). Do not try to make it exact; the point is a ceiling on the order of magnitude, and the Haiku N=100 runs projected in the README are all under $0.10, so the realistic use is a typo in `--agents`.
- The SDK retries 429/529 twice by default. Do not add a retry layer; do document in the file header that `--concurrency` is the knob for rate limits, and that an errored call is recorded and costs nothing.
- Resumability (restarting a half-finished run without re-paying) was considered and rejected for this backlog: the API runs the README projects cost cents, `partitioned` and `hierarchical` leaves are independent so a rerun is cheap, and `shared-lock` is the one topology where it would matter and the one the project already concludes nobody should run. Revisit only if a real run shows otherwise.
- Do not edit `src/cost-model.mjs` or `src/pricing.mjs`.
