# Add a test gate to package.json

`package.json` has exactly one script (`start`) and no `test`, `lint`, or `engines` entry, so there is no command a reviewer or a later task can run to decide whether the tree is green. Every other task in this backlog adds a `test/*.test.mjs` file and needs a single command that runs them all. Node 25 is installed and `node --test` is built in, so the gate needs zero dependencies.

## Acceptance
- [ ] `package.json` contains `"test": "node --test test/"` under `scripts`
- [ ] `package.json` contains `"check": "node --check src/*.mjs src/strategies/*.mjs"` (or equivalent that returns non-zero on a syntax error in any file under `src/`)
- [ ] `package.json` contains an `engines.node` field of `>=22`
- [ ] `test/smoke.test.mjs` exists and asserts that `import('../src/verify.mjs')` exports a function named `verify` and that `import('../src/cost-model.mjs')` exports a function named `project`
- [ ] `npm test` exits 0
- [ ] `npm run check` exits 0

## Notes
- This is the only first-wave task permitted to touch `package.json`. T-005 later adds the `@anthropic-ai/sdk` dependency and therefore depends on this task.
- Do not add npm dependencies here; the point is a zero-install gate.
- `node --test test/` with a directory argument requires Node 22+ (hence `engines`). The glob form `node --test "test/**/*.test.mjs"` is an acceptable alternative.
- `src/run.mjs` writes into `runs/`, which is already gitignored; the smoke test must not spawn workers (that is T-007's test).
