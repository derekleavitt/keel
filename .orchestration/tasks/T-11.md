# Organizations: everything belongs to a workspace

The largest structural change in the backlog. Nearly every platform is multi-tenant and retrofitting it later is brutal.

Proves the **tenancy** row in `docs/platform-readiness.md`. A capability is not done until
the testbed genuinely uses it, a worked example exists for it, the gate covers it, and the
vendor behind it could be swapped without touching feature code.

## Acceptance

- [ ] Users belong to organizations; lists, todos and tags belong to an organization
- [ ] Every existing query is re-scoped, with no path that forgets
- [ ] A migration moves existing rows into a personal organization
- [ ] Cross-tenant access is impossible by construction, proven by tests
- [ ] Switching organization changes what is visible everywhere at once

## Watch for

**This is the threshold feature.** It touches every package, every query and every
contract at once. If territories, impact analysis or `graph_disjoint` are ever going to
earn their place, it is here — an agent cannot hold this change in one context window.
Expect several P-* predictions to be demanded during this task.

A hypothesis, not a specification. If the friction lands elsewhere, that is the more
interesting result — record it.
