# Pilot code graph engines against this repo

Evaluate candidate engines (code-review-graph, Serena, codebase-memory-mcp) against
THIS monorepo, not against their own demos. Record results in docs/adr/0001-graph-engine.md.

The documented weakness of the leading candidate is that flow detection favours Python
over JS/TS — which is exactly this stack. Verify or refute that before adopting.

## Acceptance

- [ ] Each candidate installed and pointed at this repo
- [ ] For each: can it answer "what imports @keel/contracts", "what breaks if serverEnv changes"
- [ ] Measured index time on a cold repo and on an incremental change
- [ ] ADR written recording the choice AND the rejected options with reasons
- [ ] DECISION POINT: if run-2 agents found docs without help, note that graph value is
      context economy rather than correctness, and say so in the ADR
