# Filter a list by tag, priority and done state

Combining filters is where query composition gets real.

## Acceptance

- [x] Filters compose without any combination dropping the user scope
- [x] A test asserts `user_id` appears in the WHERE clause for every combination
- [x] An empty list and a fully-filtered list render differently (a PRD requirement)

## Watch for

many optional predicates at once.

This section is a hypothesis, not a specification. If the friction lands somewhere else,
that is the more interesting result — record it.
