# README: the first real call, what it changes, and what it does not establish

Last task of the wave, for the T-011/T-012 reason: it quotes what T-024 and T-025 produce.
`test/readme.test.mjs` pins the sentences below, so this is where the wave turns green.

Claims in the README that three real `claude -p` calls have made false, with the direction:

| claim | where | now |
|---|---|---|
| a nested `claude -p` fails with an expired OAuth session | Running real agents | false on the owner's machine; it ran three times |
| the `claude-code` rows cannot be measured at all | Running real agents, What this cannot measure | false; T-024 is the instrument |
| no real run has ever happened; every agent figure is a projection | several | three calls have happened; three claude-code constants are measured, from one machine and one session |
| a coding agent's fixed cost is roughly 15,000 tokens | What a system like that needs, What it costs | 44,541, about 3x higher, on every call |
| a Claude Code agent's round-trip latency is 8 s | What it costs | 3.0 s median of three, an upper bound; the assumption was too high |
| calls, tokens and cost do not change with concurrency; only time does | What it costs | true only under `--cache none`; under `session` cost falls as fewer calls start cold |
| the 100-agent partitioned job is $1.5012 as Claude Code agents | What it costs | $13.64 serial to $44.55 all-cold on the measured constants, 9x to 30x understated |
| the claude-code rows are priced at Haiku | the cost table | a dispatched Claude Code agent inherits the session's model; the rows are labelled with that condition |
| spin-up is "paid N times" as if each payment were the same | What it costs | the first is $0.445 and every later one is $0.133; the marginal cost plateaus and does not fall further |

The sentences that matter most go in `What it costs`, in plain words. The measured warm cost of
$0.133 per agent is 88% a block of about 11,680 prefix tokens that is re-created at the cache-write
price on every call; 32,862 tokens are read from cache for $0.016, and the task itself is 5 tokens.
Against the API path at Haiku ($0.0213 for all 100 agents) the same job dispatched as Claude Code
agents is about 640x the price, for three reasons stated separately: 3x the tokens, the session's
model instead of a chosen one, and the write price on a block that never hits. A stable prefix
would bring the warm call to about $0.022; not caching the volatile block at all would bring it to
about $0.075, because a cache write that is never read costs twice what plain input costs.
