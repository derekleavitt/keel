# README and its test: fanout honoured, the race closed, the harness's refusals, and a test that would fail on a date

Last task of the wave; it quotes what the other three produce, for the T-011/T-012 reason. Three
statements in "What this cannot measure" become false when T-020 and T-021 land, and
`test/readme.test.mjs` pins each of them, so this task is where the wave turns green.

One item is this task's own finding. `test/readme.test.mjs` asserts
`assert.equal(quoted[1], r.stderr.trimEnd())` for the `--max-spend 0.01` refusal. `src/agents.mjs`
`main()` calls `warnIfPricingStale()` first, which writes a warning line to stderr once
`PRICING_CHECKED` (2026-10-04) is more than 90 days old. **On 2027-01-03 the suite goes red with no
change to any file.** Confirmed by calling `warnIfPricingStale(checked + 91 days)`. No other test
compares stderr by equality (`cost-model.test.mjs` and the `badMock` test use `match`, which
survives).
