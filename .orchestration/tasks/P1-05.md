# PreToolUse hook: consult the graph before file search

Adopted from Graphify's best idea. The hook fires before every search tool call so an
agent physically cannot grep-spray. This is the context-economy mechanism made
involuntary rather than advisory.

## Acceptance

- [ ] Hook registered in .claude/settings.json
- [ ] Fires on Grep/Glob and injects relevant graph context
- [ ] Measured: files-read-before-correct-code drops vs the run-1 baseline of ~20-48
- [ ] Does not add more than 300ms to a search
