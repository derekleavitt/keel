# Circuit breakers

Per architecture §9. Each trip halts and writes a full-context report to
.orchestration/blocked/.

## Acceptance

- [ ] Identical verify failure 3x halts
- [ ] Task exceeding 8 iterations halts
- [ ] Contract or schema change during an autonomous run halts
- [ ] New dependency cycle halts
- [ ] Duplicate-shape symbol halts
- [ ] Falling coverage or green-test count halts
- [ ] Each writes enough context to triage without re-reading the transcript
- [ ] Every breaker has a test that trips it deliberately
