# Promote organizations out of the testbed

`Scope` is a Keel primitive. Every feature package takes one, every query is scoped by it,
and `packages/auth` and `packages/audit` both depend on the shape. The queries that produce
it — `resolveScope`, `scopeFor`, membership, invitations — live in `packages/organizations`, because
that is where multi-tenancy was first built as an experiment.

Nothing is broken. The cost is that anything genuinely platform-level which needs
organizations has to sit in `testbed/` to reach them: `packages/admin` is there for exactly
this reason and for no other, despite being Keel machinery a template user would want.

## Acceptance

- [ ] `packages/organizations` owns membership, invitations and scope resolution
- [ ] `packages/admin` moves to `packages/admin`
- [ ] No package under `packages/` imports from `testbed/`
- [ ] A lint rule enforces that direction, so it cannot decay again

## Watch for

A rename touching nearly every import in the repo. Worth doing only when something is
actually blocked by it — the direction is wrong, but wrong quietly. Pull this when a second
platform-level capability needs organizations, not before.
