# A claude-code transport for the agent harness, so the other half of the table can be measured

The README says the `claude-code` rows "cannot be measured at all" and that a nested `claude -p`
fails with an expired OAuth session. Both were true of the sandbox that wrote them and are false
of the owner's machine: a boilerplate opened in Claude Code has an authenticated session, and
`claude -p "Output the number 47. Nothing else." --output-format json` returned `47` with

```
usage.input_tokens                  2
usage.cache_creation_input_tokens   44539
usage.output_tokens                 3
total_cost_usd                      0.445475
model                               claude-opus-5[1m]
duration_api_ms 2153   ttft_ms 2170   duration_ms 3039
```

Two more calls followed, same prompt shape, same session, minutes apart:

| call | input | cache_creation | cache_read | output | cost_usd | duration_ms |
|---|---|---|---|---|---|---|
| 1 (cold) | 2 | 44,539 | 0 | 3 | 0.445475 | 3039 |
| 2 | 2 | 11,679 | 32,862 | 3 | 0.133306 | 3001 |
| 3 | 2 | 11,683 | 32,862 | 3 | 0.133346 | 2824 |

These are the first real agent calls this project has made, and they settle one question: the
marginal cost of a dispatched Claude Code agent is $0.133, and it plateaus there. The prefix has a
stable block of 32,862 tokens that is read from cache after the first call and a volatile block of
about 11,680 tokens that is re-created, at the cache-write price, on every call. (See T-025 and the
fourth grooming in BACKLOG.md.) This task builds the instrument that turns calls like these into a
record `compare.mjs` can read, with the same guardrails the API transport has, so that the first
real `claude-code` run of the harness is a decision the owner makes once and not an accident.

Three facts about the shape, which the transport must preserve rather than flatten:

- The prefix is reported as `cache_creation_input_tokens` and `cache_read_input_tokens`, not
  `input_tokens`. Priced from `src/pricing.mjs`'s opus rates, all three costs are reproduced to six
  decimals at a 2x cache-write multiplier and a 0.1x cache-read multiplier:
  `(11679 x 5 x 2 + 32862 x 5 x 0.1 + 2 x 5 + 3 x 25) / 1e6 = 0.133306`. A record that sums the
  three input fields into one `inputTokens` destroys the split that the cost depends on.
- The model is the session's, not the caller's. `--model` cannot choose it; the record has to
  carry what the CLI reported, including a suffix like `[1m]` that is not a key in `pricing.mjs`.
- The CLI reports its own `total_cost_usd`. For the mid-run ceiling that is a better number than
  anything this repository can compute, because it is the vendor's accounting of the vendor's
  cache tiers. Use it for the ceiling; store it; let `compare.mjs` (T-025) check it against the
  table.

## Acceptance
- [ ] `--kind claude-code` selects a transport that runs `claude -p <prompt> --output-format json`
      per call (via `child_process`, no shell string interpolation of the prompt), parses the JSON,
      and returns `{ text, inputTokens, outputTokens, cacheCreationInputTokens,
      cacheReadInputTokens, stopReason, model, costUsd }`. The default kind is `api` and the API
      transport is unchanged. `--kind` with any other value exits 2 naming the flag.
- [ ] With `--kind claude-code`, `--max-spend` is **required**: a run without it exits 2 before any
      call, with a message saying why (the session model is not chosen by the caller, so the
      projection cannot be trusted to bound the spend). `--model` with `--kind claude-code` exits 2
      with a message saying the model is the session's. `--dry-run` works and prints the projection
      for `kind: 'claude-code'`.
- [ ] The mid-run ceiling for this kind is enforced from the sum of the CLI's reported
      `total_cost_usd`, not from `costOf()`. The report's `cost` line for this kind says
      `(reported by claude)` after the figure.
- [ ] Each call record gains two fields, `cacheCreationInputTokens` and `cacheReadInputTokens`
      (0 for the API transport), appended after `outputTokens` so every existing key keeps its
      position. The summary line gains `kind` (`api` or `claude-code`), `cacheCreationInputTokens`,
      `cacheReadInputTokens` and `reportedCostUsd` (null for `api`), appended after `costUsd`.
      Nothing else in the record format changes; `test/compare.test.mjs` and both fixtures must pass
      untouched. These field names are the contract with T-025, which reads them.
- [ ] `inputTokens` on a claude-code record is the CLI's `input_tokens` only, never a sum that
      includes either cache field. A test asserts it from a scripted CLI output.
- [ ] The transport is tested without running `claude`: tests inject a fake executable path (or
      a `deps.spawn`) that prints a canned JSON document, including one with
      `cache_read_input_tokens` non-zero and `cache_creation_input_tokens` zero, one with a
      non-zero exit and stderr (recorded as `errored`, with the stderr in the error string), one
      with `is_error: true` in the JSON, and one with a model id carrying `[1m]`. The `claude`
      binary absent on PATH is an exit-2 refusal with the binary named, tested the same way.
- [ ] `test/fixtures/claude-p-47.json` is a JSON **array** of the three **verbatim** documents the
      owner's calls printed, in call order, saved by whoever has them; if the dispatcher cannot
      supply them verbatim, the file is not created and the report says so. It is the first fixture
      in this repository that is a measurement and not synthetic, and its first character is `[`,
      not a `#` comment. A test parses it, asserts the table above field for field
      (`cache_creation_input_tokens` 44539 / 11679 / 11683, `cache_read_input_tokens` 0 / 32862 /
      32862, `total_cost_usd` 0.445475 / 0.133306 / 0.133346), and asserts the transport's parser
      produces the matching `cacheCreationInputTokens` and `cacheReadInputTokens` from each.
- [ ] `npm run check` exits 0. `npm test` exits 0 **except** the `test/readme.test.mjs` test
      `every flag and KEEL_ variable read by the source is documented`, which will flag `--kind` as
      undocumented until T-026. No other test may fail; say so in the report.

## Notes
- Do not run `claude -p` in tests or in this task at all. Each call costs $0.13 warm and $0.45
  cold at the owner's session model, three calls ($0.71) were all the owner authorised, and no
  further calls are authorised. The fixture is supplied, not generated.
- Keep `arg('agents', 10)`, `arg('concurrency', 20)`, `arg('fanout', 10)` as literal source text
  and read new flags with `arg(...)`; `test/readme.test.mjs` extracts flags by regex from them.
- The model string the CLI reports (`claude-opus-5[1m]`) is stored as reported. Do not strip the
  suffix in the record; T-025 decides how to price it.
- `README.md` and `test/readme.test.mjs` are T-026's. Do not edit them.
