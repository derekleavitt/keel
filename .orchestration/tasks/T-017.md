# Compare a recorded run against the cost model's assumptions

The README's cost table rests on five numbers nobody has measured: `OVERHEAD.api = 200`,
`TOKENS_PER_NUMBER = 2.5`, `OUTPUT_TOKENS_PER_SECOND = 100`, `LATENCY.api = 1.5`, and the
assumption that a call's input is overhead plus the numbers it is shown. Each one can be read
off a T-015 record without argument:

- **overhead (api)**: median `inputTokens` of `leaf` calls — their prompt is the system prompt
  plus "Output the number N. Nothing else.", about 45 tokens by a chars/4 count, against the
  assumed 200. If that holds, the projected cost of every API row is 3–4× too high, and the
  dollar figures in the README are wrong in the model's favour.
- **tokens per number**: median `outputTokens` of `leaf` calls (one number each), and
  `outputTokens / valuesOut` over `merger`, `root`, `shared` and `solo` calls (many).
- **output tokens per second and fixed latency**: least-squares slope and intercept of `ms`
  against `outputTokens` over all accepted calls. The intercept is `LATENCY` in ms; the slope is
  `1000 / OUTPUT_TOKENS_PER_SECOND`. With only leaf calls (all ~2 output tokens) the fit is
  degenerate; say so and report the intercept only.
- **the totals**: measured `inputTokens`, `outputTokens`, `costUsd`, `elapsedMs` against
  `project({ agents, topology, model, kind: 'api', concurrency })` for the run's own parameters,
  read from the summary line.

`node src/compare.mjs <record.jsonl>` prints one line per assumption: what the model assumes,
what the record measured, and the ratio. It changes nothing; it is the instrument the README's
"Measure it" item has been missing. When a real record exists, the output of this tool is what
replaces the constants — by data, not by a task that argues for a different round number.

## Acceptance
- [ ] `src/compare.mjs` exports `compare(records)` taking the parsed array of record objects (call lines plus the summary line, in the T-015 format) and returning `{ assumptions: [{ name, assumed, measured, ratio, note }], totals: { input, output, costUsd, seconds }, projected: { input, output, cost, seconds } }`; it imports `ASSUMPTIONS` and `project` from `./cost-model.mjs` and never hardcodes a model constant
- [ ] `assumptions` always contains names `overhead.api`, `tokensPerNumber.single`, `tokensPerNumber.list`, `latencyMs`, `outputTokensPerSecond`; `measured` is `null` with a `note` when the record cannot support it (no list calls, fewer than 3 distinct `outputTokens` values for the fit, all tokens zero as in a mock run)
- [ ] `test/fixtures/record-partitioned.jsonl` is a hand-written 100-agent partitioned record on `claude-haiku-4-5` whose call lines satisfy `ms = 1500 + 10 * outputTokens` exactly with `inputTokens` 45 and `outputTokens` 2; `test/fixtures/record-hierarchical.jsonl` is a 12-agent fanout-3 record (19 calls) with the same linear law and `outputTokens = 2 * valuesOut`; a test asserts the hierarchical fixture yields `latencyMs` within 1% of 1500, `outputTokensPerSecond` within 1% of 100, `overhead.api` of 45, `tokensPerNumber.list` of 2, and the partitioned fixture yields `outputTokensPerSecond: null` with a note matching `/degenerate|distinct/`
- [ ] The CLI prints, for each assumption, a line matching `^\S+\s+assumed \S+\s+measured \S+\s+ratio \S+` (with `measured -` and `ratio -` when null) and a final block `totals` with four lines each matching `^(tokens in|tokens out|cost|time)\s+projected \S+\s+measured \S+\s+ratio \S+`; a test spawns it on each fixture and asserts the patterns and exit 0
- [ ] `node src/compare.mjs` on a record produced by `node src/agents.mjs --agents 12 --topology hierarchical --fanout 3 --mock clean --record <tmp>` exits 0 and reports every token-derived assumption as `measured -` with a note containing `mock` or `zero tokens`, rather than reporting a ratio against zero
- [ ] A missing file, a file with no summary line, or a line that is not JSON exits 2 with a message naming the problem
- [ ] `--json` prints the `compare()` return value as JSON and nothing else
- [ ] `node --test test/compare.test.mjs` exits 0; `npm run check` exits 0 (the `check` script globs `src/*.mjs`, so the new file is covered)
- [ ] `npm test` exits 0 **except** `test/readme.test.mjs`'s test "layout block lists every source file", which fails until T-019 adds `src/compare.mjs` to the README's Layout block; no other test may fail
