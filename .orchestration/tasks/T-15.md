# Public API with API keys

Session cookies do not work for machines.

Proves the **external api** row in `docs/platform-readiness.md`. A capability is not done until
the testbed genuinely uses it, a worked example exists for it, the gate covers it, and the
vendor behind it could be swapped without touching feature code.

## Acceptance

- [ ] API keys issued per organization, hashed at rest, revocable
- [ ] Key auth and session auth share one authorization path
- [ ] Versioned, documented endpoints for lists and todos
- [ ] A test proves a key scoped to one organization cannot read another

## Watch for

Second authentication mechanism. Whether `requireUser()` generalises or has to be
rebuilt is exactly the kind of thing only a second caller reveals.

A hypothesis, not a specification. If the friction lands elsewhere, that is the more
interesting result — record it.
