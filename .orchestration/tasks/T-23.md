# A notes editor for a todo

`todo.notes` is in the schema, settable through the public API, searchable, and shown as the
snippet in search results. There is no way to set it in the app.

Found while writing a browser test for T-19 that tried to type into a field which does not
exist. The data model, the API and the search index all support notes; only the interface
does not.

## Acceptance

- [ ] Notes are editable from the todo row, saved without a separate form submit
- [ ] Editing notes changes what the todo matches in search
- [ ] A viewer on a shared list cannot edit them

## Watch for

Small, and the point is the gap itself: a field can be complete everywhere except the one
place a user would meet it, and every layer's tests still pass.
