# Make agents.mjs runnable offline and fix its answer parsing

`src/agents.mjs` has never executed past line 56. Even with credentials it would fail: it dynamically imports `@anthropic-ai/sdk`, which is not declared in `package.json` and is not installed (`ERR_MODULE_NOT_FOUND`). Its parsing has two bugs that the oracle would report as the model's fault: in `partitioned`, `Number(String('').replace(...))` is `0`, which passes `Number.isFinite` and lands in the file as `unexpected: [0]`; in `shared-lock`, `answer.replace(/[^\d,\-]/g, '')` turns a newline-separated reply `"1\n2\n3"` into `"123"` — an invented number. It also shuffles with `sort(() => Math.random() - 0.5)`, which is biased. A `--mock` transport makes all of this testable without a key.

## Acceptance
- [ ] `package.json` declares `@anthropic-ai/sdk` under `dependencies` (do not commit `node_modules`; a lockfile is optional)
- [ ] `src/agents.mjs` accepts `--mock <clean|prose|newline|empty>` which replaces the SDK call with a local function returning, respectively: the exact expected value; the value wrapped in a sentence; the list joined with `\n` instead of `,`; an empty string. In mock mode the credential check and SDK import are skipped
- [ ] `node src/agents.mjs --mock clean --agents 20 --topology partitioned` exits 0 with no `ANTHROPIC_API_KEY` set
- [ ] `node src/agents.mjs --mock newline --agents 10 --topology shared-lock` exits 0 (regression for the `"123"` bug)
- [ ] `node src/agents.mjs --mock empty --agents 5 --topology partitioned` exits 1 and its output contains `missing` but not `unexpected: [0]`
- [ ] Shuffle uses a Fisher–Yates loop (as in `src/run.mjs`), not `sort(() => Math.random() - 0.5)`
- [ ] `test/agents.test.mjs` spawns the three commands above and asserts exit codes; `node --test test/agents.test.mjs` exits 0
- [ ] Measured-cost output line (`cost $...`) is still printed in mock mode with tokens counted as 0
