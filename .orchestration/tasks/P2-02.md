# Doc frontmatter schema and signature hashing

`covers:` plus `sig:`. CRITICAL: hash PUBLIC SIGNATURES, not file bodies. Hashing
bodies marks half the docs stale on every commit and the gate gets switched off within
a week. This distinction is the whole design.

## Acceptance

- [ ] Zod schema for doc frontmatter in packages/contracts
- [ ] Signature hash is stable across an internal-only edit (rename a local variable)
- [ ] Signature hash CHANGES when a parameter, column or return type changes
- [ ] Both properties covered by tests — this is the load-bearing behaviour
