# Implement solo and hierarchical topologies in agents.mjs

`src/cost-model.mjs` projects four topologies (`solo`, `shared-lock`, `partitioned`, `hierarchical`) and the README's cost table reports all four, but `src/agents.mjs` implements only `partitioned` and `shared-lock` and exits 2 for anything else. The README's headline comparison — solo at $0.0015 versus everything distributed — can therefore never be measured, and the "interesting middle" the cost model comments describe has no implementation at all. Both are needed before the projection-versus-measurement comparison the project exists for can be made.

## Acceptance
- [ ] `node src/agents.mjs --mock clean --agents 30 --topology solo` exits 0 using exactly 1 model call (output line `calls    1`)
- [ ] `node src/agents.mjs --mock clean --agents 30 --topology hierarchical --fanout 10` exits 0 using 30 + 3 + 1 = 34 calls (output line `calls    34`), with per-group merge calls and one root merge call
- [ ] `--fanout` defaults to 10 and is accepted on the CLI
- [ ] `node src/agents.mjs --mock newline --agents 30 --topology hierarchical` exits 0
- [ ] `test/agents-topologies.test.mjs` imports `TOPOLOGY_NAMES` from `../src/cost-model.mjs` and asserts that each name is accepted by `agents.mjs` in mock mode (exit 0), so the two files cannot silently diverge again
- [ ] `node --test test/` exits 0
