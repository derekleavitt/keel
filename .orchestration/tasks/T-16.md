# Outbound webhooks on todo events

Integration is table stakes for a platform.

Proves the **integration** row in `docs/platform-readiness.md`. A capability is not done until
the testbed genuinely uses it, a worked example exists for it, the gate covers it, and the
vendor behind it could be swapped without touching feature code.

## Acceptance

- [ ] Subscribe to events per organization
- [ ] Delivery is retried with backoff and signed so receivers can verify
- [ ] Failures are visible and replayable
- [ ] A slow receiver cannot slow down the app

## Watch for

Depends on the queue from T-12 being genuinely reusable rather than shaped only for
email.

A hypothesis, not a specification. If the friction lands elsewhere, that is the more
interesting result — record it.
