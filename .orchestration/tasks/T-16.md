# Outbound webhooks on todo events

Integration is table stakes for a platform.

Proves the **integration** row in `docs/platform-readiness.md`. A capability is not done until
the testbed genuinely uses it, a worked example exists for it, the gate covers it, and the
vendor behind it could be swapped without touching feature code.

## Acceptance

- [x] Subscribe to events per organization
- [x] Delivery is retried with backoff and signed so receivers can verify
- [x] Failures are visible and replayable
- [x] A slow receiver cannot slow down the app

## Watch for

Depends on the queue from T-12 being genuinely reusable rather than shaped only for
email.

A hypothesis, not a specification. If the friction lands elsewhere, that is the more
interesting result — record it.

## Outcome

The queue **was** reusable — `enqueue`, backoff, dead-lettering and the registry took a
second consumer unchanged. It had also never run: the first HTTP drain threw twice on
driver differences PGlite hides. See `.orchestration/journal/2026-08-27-T-16.md` and
[[L-033]].

The **Watch for** asked the right question and got a yes. The valuable finding was to a
question it did not ask — whether "done" had ever meant "executed".
