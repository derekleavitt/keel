# typedRoutes cannot typecheck a route that has not been built

## Friction

`typedRoutes: true` types `Link href` and `router.push()` against the routes that exist —
but those types are generated during `next build` or `next dev`. The gate runs typecheck
*before* build, so on a clean tree **every newly added route fails typecheck**, with six
errors that read as if `Link` is broken rather than as if types are missing.

Adding the first four routes to this app produced exactly that, and nothing in the repo
explains it. An agent hitting this will reasonably conclude `typedRoutes` is the problem
and turn it off, losing a real safety property.

`next typegen` generates them without a full build, so the fix is to run it as part of the
package's typecheck rather than relying on a prior build having happened.
