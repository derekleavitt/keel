# Pin the cost model with tests and fix its modelling errors

The README table is generated by `src/cost-model.mjs` and nothing checks it. Running it exposed four problems. (1) `hierarchical` charges the root merger `fanout * TOKENS_PER_NUMBER` = 25 input tokens for reading all 100 numbers, and for N > fanout² (e.g. 1000) it still models exactly one merge level with `groups + 1` calls — the comment's claim that "no agent sees more than fanout numbers" is false for the root, and the true shape is O(N·log_fanout N) tokens, not O(N). (2) The header documents `--verbose` but no code reads it. (3) `--model gpt` crashes with an uncaught TypeError on `MODELS[model].id`. (4) Odd N prints fractional token counts (`1452.5`). It also has the same `import.meta.url` main-check bug as `verify.mjs`.

## Acceptance
- [ ] `test/cost-model.test.mjs` exists and `node --test test/cost-model.test.mjs` exits 0
- [ ] Tests pin `project({agents:100, kind:'api', topology})` for `solo` (input 200, output 250), `partitioned` (input 20000, output 250), `shared-lock` (input 32375, output 12625) — these must not change
- [ ] `hierarchical` is modelled with explicit levels: each merger's input is `fanout × (numbers per child) × TOKENS_PER_NUMBER` and the root reads all N; a test asserts `project({agents:100, topology:'hierarchical', kind:'api'}).input` equals the value computed from that formula (22700 for the current constants) and that `project({agents:1000, topology:'hierarchical'}).calls` is 1000 + 100 + 10 + 1 = 1111
- [ ] `project()` throws an `Error` whose message contains `unknown model` / `unknown topology` for bad names, and the CLI exits 2 with that message on stderr (test spawns `node src/cost-model.mjs --model gpt` and asserts exit code 2)
- [ ] Either `--verbose` prints, per row, the overhead, per-call input/output and rounds used, or the `--verbose` line is removed from the header comment; a test asserts whichever was chosen
- [ ] `input` and `output` in `project()` results are integers (`Math.round`), asserted for `--agents 7`
- [ ] Main-module detection uses `fileURLToPath(import.meta.url)` vs `path.resolve(process.argv[1])`
- [ ] `node src/cost-model.mjs --agents 100` exits 0 and prints 8 data rows
