# A vendor's required schema was hand-written, incomplete, and green

`packages/db/src/schema/auth.ts` was written from memory of what the Better Auth adapter
requires. It was missing `account.issuer`, so **every sign-up returned a 500**.

Nothing caught it. Typecheck passed, lint passed, unit tests passed, `next build` passed,
and the PGlite suite exercised those very tables — because it inserted into them directly
rather than going through the library. Six agents worked in this repo without noticing,
since none of them ever signed a user up.

**Typechecking a vendor's required schema proves nothing.** Only the vendor's code knows
what it needs, and the only way to ask is to call it.

The enforcement is an e2e test that performs a real sign-up against a real database. It
would have failed on the first run. Related: [[L-011]].
