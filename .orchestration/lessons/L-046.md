# A limit is a product decision, and picking the number is not the small part

Adding seat enforcement broke every sharing test at once. Not the mechanism — the mechanism
was ten lines, copied from the list limit and correct on the first run. The number.

The free plan allowed **one** seat. So no free user could ever share a list, invite anybody,
or use an organization for anything — the testbed's central feature became a paid feature,
decided by a constant nobody had thought about as a decision. The suite reported it
immediately and unambiguously: five sharing tests, all red.

The tempting reading is "the tests need updating to buy a plan first". That would have been
the wrong fix twice over. It would have shipped the pricing decision, and it would have
coupled every multi-user test to billing — so a change to plans could break sharing, and a
change to sharing would need a billing fixture.

Free now allows three: small enough that the limit is still demonstrable (a fourth member is
refused, and there is a test), large enough that the feature it governs is usable without a
subscription.

**When a limit lands on an existing feature, the number decides whether that feature still
exists.** Worth asking explicitly, before the constant is written: what can somebody do at
zero? For a template the answer should almost always be "everything, a bit" rather than "some
things, fully" — a reader evaluating it will hit the free tier, and a paywalled core reads as
the product not working.

## The second decision, which is easier to get right and worse to get wrong

Enforcement applies only when **adding** somebody. A tenant that downgrades from ten seats to
three still has ten people, and locking seven of them out to enforce a number is a far worse
outcome than letting the count sit over the limit. The limit governs growth, not existing
state — so changing an existing member's role still works, and nobody is ever removed by a
billing event.

Related: [[L-045]], where an address limit was set too tight and the browser suite tripped it
against itself. Same shape, twice in one session: the mechanism was easy and the number was
the design.
