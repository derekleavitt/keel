# userIdSchema lived in the barrel, forcing a TDZ cycle on any feature contract needing it

CLAUDE.md warns never to import from a barrel that re-exports you — TDZ crash, no lint
error, no type error. But userIdSchema was defined IN the barrel, so any feature contract
needing it was pushed into exactly that cycle.

Fixed structurally by moving it to a leaf module. The test asserts the barrel defines no
schemas of its own, so the trap cannot be rebuilt.
