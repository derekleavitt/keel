# Committing a baseline migration turned a 2-way conflict into a guaranteed 3-way one

Run 1: two branches generated conflicting baselines. The fix let all three generate a
clean 0001 delta — and collide on 0001_snapshot.json and _journal.json.

The real fix is that feature branches must not generate migrations at all. Only the
integrator runs db:generate, once, after merging. A structural change that relocates a
problem is not a fix.
