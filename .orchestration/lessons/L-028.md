# A wrapper that hides the database handle cannot be adopted by anything that injects one

T-14 opened with a `withAudit(operation, describe)` combinator: wrap a mutation, and the
audit entry could not be forgotten. It typechecked, it read well in its own docstring, and
no call site could use it.

Two reasons, and the second is the one that generalises.

**It could not see what happened.** Wrapping from outside, all it has is the return value.
Only the code performing the change knows it renamed a list *from* one name *to* another.
A wrapper can record that a write occurred; "row updated" is not an audit log.

**It could not thread the connection.** Every query helper here takes `database` as a
trailing parameter with a `db()` default, so tests inject PGlite and transactional
mutations pass a `tx`. `withAudit` forwards `...args` opaquely — it cannot know which of
them is the connection, so it logged through the default `db()` while the write went
somewhere else. Every injected-database test would have opened a real connection, and the
transactional delete could not have logged atomically with itself.

The fix was to move the call *down*, not to make the wrapper cleverer: `audit()` goes
inside the query helper, beside the write, where the row and the handle are both in scope.

That relocation turned out to matter for a reason unrelated to testing. **Server actions
are not the only entry point.** T-15 adds a public API and T-16 adds webhooks, both
reaching the same query helpers directly. Auditing in the action layer would have recorded
what the browser did and silently missed everything else — a gap that would have looked
like working software right up until someone asked why API activity was invisible.

**Put cross-cutting effects at the layer that owns the resource, not the layer that owns
the request.** The request layer changes shape every time an entry point is added; the
resource layer does not. And an abstraction no call site can adopt is not an abstraction —
deleting it is cheaper than the second attempt to make it fit.
