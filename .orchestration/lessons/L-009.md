# drizzle date() default mode returns string; mode: 'date' reintroduces the timezone bug

The PRD names timezone handling as the classic failure in this category, and the
column type that causes it is one option object away. An agent read date.d.ts rather than
guessing, then added a test querying information_schema to assert the SQL type is date.

That test is the enforcement: a future schema edit cannot silently flip it.
