# types: [node] is needed transitively, not only for direct Node API use

CLAUDE.md scoped the rule to "packages that use Node APIs". packages/lists uses none,
but tsc follows into source-exported dependencies and failed with TS2591. The rule is
"any package that transitively imports one". Cost an agent a cycle.
