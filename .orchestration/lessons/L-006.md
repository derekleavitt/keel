# Subagents inherit the parent session's CLAUDE.md, not their working directory's

An agent working in keel-todo2 was injected with Keel's CLAUDE.md from the parent
session's cwd — an older, shorter version missing five conventions. It noticed and read
the worktree copy; had it trusted the injected file it would have missed .claude/rules/
entirely.

Any prompt spawning an agent into a different repo must tell it explicitly to read that
repo's CLAUDE.md rather than relying on injection.
