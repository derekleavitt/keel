# T-08 — search, and the ADR's first refinement

62 unit tests across the two packages, 7 browser tests, 37 browser tests total green.

## The escaping actually matters

`%` and `_` are SQL wildcards. Typed by a user they are literal characters, and a search
for `50%` that quietly matches everything starting with `50` is both wrong and, on a large
table, a way to make the database do far more work than was asked of it.

The backslash has to be escaped **first** — escaping the wildcards first would then
re-escape the backslashes just added. There is a test for that ordering specifically,
because getting it backwards produces a subtly broken escape that still passes a naive test.

Both are asserted twice: against rendered SQL, and in a browser against real Postgres.

## The ADR needed refining at n=2

ADR 0001 said cross-feature reads live in a package depending on several features and
depended on by nothing but the app. Search is the second such view, and it exposed two
things the first instance could not:

**The unit is the composition *layer*, not one package per view.** `testbed/agenda` was a
fine name for one view and the wrong name for a package that also holds search. Renamed to
`testbed/views` at two instances, while the change was still cheap. Waiting for a third
would have meant either a worse name or a bigger rename.

**Only the crossing part composes.** Search's query lives in `todos` — title and notes are
todo columns, and the escaping belongs with the table it protects. Only "which list is this
in" crosses a boundary, and only that lives in the view. Moving the whole query up because
its *results* are displayed across features would have hollowed out the feature package,
which is the same decay T-07 caught pointing the other way.

## What went smoothly

No new Keel capability was needed. `queryBuilder()`, the branded `UserId`, `ownedBy()`, the
composition pattern and the PGlite seam all applied without adaptation — the first feature
where existing machinery covered everything and the only work was the feature itself.

Worth recording as the result being looked for, not just an absence of findings.
