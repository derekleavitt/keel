# T-01 — sign up, sign in, sign out

First feature completed under the loop protocol. Seven e2e tests green against a real
database: sign-up, wrong-password rejection, anonymous redirect, session surviving a
reload, sign-out, and signing back in.

## Friction promoted

**K-002 — `typedRoutes` cannot typecheck an unbuilt route.** Route types are generated
during build; the gate typechecks before building. Adding four routes produced six errors
that read as if `Link` were broken. Fixed by running `next typegen` as part of the
package's typecheck.

Chasing that surfaced something larger. TypeScript 7 could not resolve Next's
`typedRoutes` ambient namespace at all — six errors under TS7, zero under TS5 on identical
code. Phase 0 had pinned TS7 because the Go rewrite is "much faster", a claim never
measured. Measured: **TS7 636ms, TS5 573ms.** TypeScript 5 is faster here. The choice cost
a real safety feature to buy a benefit that did not exist. Now pinned to 5.9.3. [[L-013]]

**No redirect variant of `requireUser()`.** It throws, which is right for a server action
and wrong for a page — a signed-out visitor opening a protected page is ordinary, not an
error. Each page inventing its own session resolution is the duplication the session
helper exists to prevent, so `requireUserOrRedirect()` now lives beside it. [[L-014]]

## What went well

`examples/notes` was not needed — this feature has no query layer — but the boundary rules
held without effort. `apps/web` never imports `better-auth`; it goes through
`@keel/auth/client` and `@keel/auth/session`. The vendor stayed behind its package with no
temptation to reach around it.

## Note on the protocol

Step 4 caught both items, but only because the first failure forced a real investigation.
The tempting shortcut at the six-error typecheck was to disable `typedRoutes` and move on —
that would have shipped a working feature, hidden a Phase 0 mistake, and quietly removed a
safety property. Worth watching for in later iterations: the friction that matters is often
disguised as an obstacle to route around.
